# HQ Auto-Unsubscribe

HQ Auto-Unsubscribe is a self-hosted, personal-use tool that helps its owner
unsubscribe from mailing lists in their own Gmail account.

It checks incoming messages for unsubscribe instructions, verifies the sender,
requests supported unsubscribes, and labels and archives the corresponding
messages. Ambiguous requests, logins, and CAPTCHAs are not completed automatically.
It cannot guarantee that senders will honor unsubscribe requests.

This application is not offered to other users. The service runs on the owner's
private server. This website contains documentation only and cannot access Gmail.
